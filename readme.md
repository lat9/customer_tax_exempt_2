# Customer Tax Exempt &mdash; v2

This plugin is based on the [Customer Tax Exempt](https://www.zen-cart.com/downloads.php?do=file&id=405) plugin, with the exception that _this_ plugin has no core-file modifications required and supports **only** Zen Cart v1.5.6 through v2.0.1 (`v2.x.x`) or Zen Cart v2.1.0 and later (`v3.x.x`).

 Click [here](https://www.zen-cart.com/showthread.php?225857-Customer-Tax-Exempt-v2-Support-Thread) to view its support-thread on the Zen Cart forums and [here](https://www.zen-cart.com/downloads.php?do=file&id=2259) to view its Zen Cart Plugins download link.

View the plugin's [readme.html](https://htmlpreview.github.io/?https://github.com/lat9/customer_tax_exempt_2/blob/master/readme.html).
